# DM Sans

Copyright 2014 The DM Sans Project Authors
(https://github.com/googlefonts/dm-fonts).

Source: [DM Sans in Google Fonts](https://github.com/google/fonts/tree/main/ofl/dmsans).
The upright variable font was converted from the original TrueType file to
WOFF2 with FontTools, retaining its glyphs, names and variable axes (weight
100–1000 and optical size 9–40).

Distributed under the [SIL Open Font License 1.1](OFL.txt).
The font is bundled locally for interface text and brush annotations;
unsupported glyphs, including Japanese characters, use system fallbacks.
